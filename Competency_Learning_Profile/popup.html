📚 FCI CALP Assistant

Competency And Learning Profile request assistant for FCI HRMS.

Stage 1: Auto-routes to assistant for review.
Stage 2: Opens attachment in background + shows remark panel.

How to use:
1. Navigate to Competency And Learning listing
2. Click ✓ on any pending request
3. Stage 1: extension fills Add Reviewer form — you click Add
4. Stage 2: select remark from panel, click Fill, then Approve/Reject
Extension is running

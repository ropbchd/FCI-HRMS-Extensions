📋 FCI Leave Encashment Assistant

Active on FCI HRMS Leave Encashment review pages.

Stage 1: Routes request to assistant for eligibility check.

Stage 2: Fills final approval remark with dynamic values.

How to use:
1. Navigate to Leave Encashment listing page
2. Extension auto-opens the first pending request
3. If Stage 1 → fills Add Reviewer form, you click Add
4. If Stage 2 → fills final remark, you click Review
Extension is running
